# Laufzeit-Rechner

Eine einzelne, in sich geschlossene HTML-App (Dark-Theme, iPhone-first) für leistungsorientierte Läufer. Kein Server, keine Installation, keine Datenspeicherung — alles läuft lokal im Browser.

## Funktionen

- **Was-wäre-wenn-Rechner** — Referenzlauf auf eine Zieldistanz hochrechnen, mit Korrekturen für Höhenmeter, Körpergewicht, Schuhe, Windschatten und Wind.
- **Kilometer-Orakel** — Richtwerte für einen langen Einzellauf aus dem 3-Tages-Schnitt.
- **Wettkampf- & Trainings-Puls** — Ziel-Puls-Korridore je nach Belastungsdauer.
- **VDOT-Trainingstempi** — Trainingszonen (Regeneration, ruhiger/zügiger Dauerlauf, Marathon, Schwelle, Intervall, Wiederholung) mit Tempo und Puls, marathontempo-verankert und proportional skaliert.
- **Puls ↔ Tempo ↔ Laktat-Kurve** — interaktives Diagramm mit farbigen Zonen.

## Nutzung

`index.html` im Browser öffnen — fertig.

Auf dem iPhone: Seite in Safari öffnen → Teilen → **„Zum Home-Bildschirm"** für ein App-artiges Vollbild-Icon.

## Hinweis

Diese App liefert ausschließlich **rechnerische Schätzwerte zu Informations- und Unterhaltungszwecken**. Sie ersetzt keine medizinische, sportmedizinische oder trainingswissenschaftliche Beratung. Höre auf deinen Körper und brich jede Belastung bei Beschwerden sofort ab. Die Nutzung erfolgt auf eigene Verantwortung.
